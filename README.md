# 🚀 English Mastery Roadmap: Tech & Fluency (B2/C1)

Um guia interativo e prático focado em acelerar a fluência em inglês para profissionais de tecnologia, aplicando o método natural (*comprehensible input*), imersão ativa/passiva e rotinas de 30 minutos diários.

## ✨ Recursos

- **Cronograma Estruturado**: Fases mensais detalhadas com atividades diárias de 30 minutos.
- **Painel Interativo de Progresso**: Acompanhamento em tempo real de dias concluídos e vocabulário ativo absorvido.
- **Foco no Mercado Tech**: Vocabulário, termos e situações reais de engenharia de software, produtos e liderança.
- **Persistência Local**: Todo o progresso salvo automaticamente no navegador (`localStorage`).
- **Design Moderno & Responsivo**: Interface escura construída com Tailwind CSS.

## 🛠️ Tecnologias

- HTML5 / CSS3 (Tailwind CSS)
- Vanilla JavaScript
- LocalStorage API
